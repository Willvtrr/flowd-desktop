# flowd — módulos nativos

Fontes públicas do capturador de tela do flowd para macOS 14 ou posterior. O aplicativo principal continua em seu repositório privado.

## Instalar com o Codex

Abra a [release mais recente](https://github.com/Willvtrr/flowd-desktop/releases/latest), copie o conteúdo de `INSTALAR-CAPTURAS-NO-CODEX.txt` e cole no Codex do seu Mac. Ele verificará o ZIP e compilará o capturador localmente com as ferramentas oficiais da Apple.

O processo preserva o flowd principal e seus dados. Este canal distribui fontes para build local; não oferece um instalador assinado nem atualização automática do aplicativo inteiro.

As fontes usam a licença MIT incluída no ZIP. Marcas e ativos visuais seguem os avisos de terceiros do pacote.
